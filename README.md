# Batalha Naval Simplificada 🚢💥

Este repositório contém o Exercício Programa (EP) desenvolvido para a disciplina de **Design de Software** do curso de Engenharia do Insper. O projeto consiste em uma implementação via terminal do clássico jogo Batalha Naval.

## 🎯 Objetivo do Jogo

O objetivo é afundar todos os navios inimigos antes que o adversário afunde os seus. O jogo exige posicionamento estratégico das embarcações no início da partida e lógica para os ataques ao longo dos turnos.

## ⚙️ Características do Projeto

* **Interface:** Terminal (Console), operado inteiramente através de comandos de texto (`print` e `input`).
* **Tabuleiro:** Grid de 10x10.
* **Frota:** 10 embarcações divididas em 4 tipos diferentes (com tamanhos variados que ocupam múltiplos espaços no grid).
* **Funcionalidades Implementadas:**
* Definição e validação de posições.
* Preenchimento e posicionamento da frota no tabuleiro.
* Lógica de jogadas (jogador e oponente).
* Verificação de navios afundados.



## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Python (Laços de repetição, Dicionários, Listas, etc.)
* **Controle de Versão:** Git e GitHub (commits atômicos para cada funcionalidade desenvolvida).

## 🚀 Como Executar

1. Clone este repositório: `git clone <link-do-seu-repositorio>`
2. Acesse a pasta do projeto: `cd <nome-da-pasta>`
3. Execute o arquivo principal do jogo (ex: `python jogo.py` ou o nome do seu arquivo de execução).
