# Batalha Naval Simplificada

Jogo de Batalha Naval desenvolvido em Python para a disciplina de Design de Software do Insper.

Jogue pelo terminal em um tabuleiro 10×10: posicione seus 10 navios e alterne ataques com o computador. Vence quem afundar primeiro toda a frota adversária.

## Como executar

Requer Python 3, sem dependências externas.

```bash
git clone https://github.com/eduamarques/Batalha-Naval-Simplificada.git
cd Batalha-Naval-Simplificada
python3 programa.py
```

Siga as instruções do terminal, usando coordenadas de 0 a 9.
